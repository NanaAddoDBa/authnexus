# AuthNexus API

This ASP.NET Core project is the future AuthNexus API host. V0.1 Phase A establishes its project
boundary only. It intentionally exposes no authentication routes, session behavior, or provider
integration yet.

The API is composed from the projects under `src/backend/`. V0.1 later phases introduce domain
models, persistence, transactions, sessions, policy contracts, audit, and the outbox in that
order.
