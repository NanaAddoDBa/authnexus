## V0.1 exit gate

The eventual release must start the web, API, and dependency stack; resolve an application
profile; execute an authentication transaction lifecycle; issue and revoke a server-managed
session; enforce redirect and policy boundaries; persist audit/outbox records; and pass its defined
tests. Phase B supplies dependencies only and satisfies none of the product-behavior items by
itself.

## Next atomic step

Phase C should replace the `src/backend/Modules/README.md` map with concrete, compilable module
boundaries and automated dependency checks. It should not add domain entities, persistence, or an
authentication endpoint early.
