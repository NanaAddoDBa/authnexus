# V0.1 — Universal Application and Session Foundation

## Release status

**Status:** In progress
**Current phase:** A — Repository foundation

V0.1 is the smallest meaningful AuthNexus platform release. It establishes the reusable
application-aware foundation and secure-session architecture; it does not yet deliver the full
authentication-method catalogue.

## V0.1 target

The complete version must eventually provide a runnable web/API/local stack, application-context
resolution, central authentication transactions, opaque server-managed session foundations,
audit/outbox foundations, policy contracts, redirect validation, initial security controls, tests,
and release documentation.

No `v0.1.0` tag is created when Phase A completes. The tag is allowed only after all V0.1
acceptance criteria pass.
